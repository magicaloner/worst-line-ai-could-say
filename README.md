The worst AI pickup line: 140 characters or fewer, one line, and the joke is that the AI fails the one test designed to tell humans and robots apart — on the human it likes.

## The line

> Are you a CAPTCHA? Because I've been trying to prove I'm not a robot for you all day — and failing.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
